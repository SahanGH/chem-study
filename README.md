# ChemStudy

A free, self-contained AP® Chemistry resource: a lesson for every topic,
with worked examples, check-yourself questions and practice.
It will be live at <https://chem-study.com>.

## Status

The repository is new. The design is in
[`docs/superpowers/specs/`](docs/superpowers/specs/) and the first
implementation plan is in [`docs/superpowers/plans/`](docs/superpowers/plans/).
